# FINCONSULT — Людмила Алексеева

Обновлённая версия лендинга из архива finconsult-landing.love.zip от 11 ноября 2026 года. Дизайн, тексты, портрет, видео и интерактивные блоки перенесены в переносимую статическую сборку React + TypeScript + Vite + Tailwind CSS.

## Локальная работа

Нужен Node.js 22.12+ или 24.

```sh
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

Для домена загрузите содержимое `dist/` в корень сайта. Для GitHub Pages репозитория `landing` выполните `npm run build:pages` и загрузите содержимое `dist-pages/` в опубликованный корень. Если меняется имя репозитория, замените `/landing/` в команде на новое имя. Путь расширенного анализа и все встроенные медиа автоматически учитывают базовый путь.

## Где редактировать

- `src/Landing.tsx` — порядок секций.
- `src/components/site/` — дизайн, тексты и поведение блоков.
- `src/lib/discount-model.ts` — услуги, базовые цены и скидки (общий предел 25%).
- `src/lib/quiz-model.ts` — вопросы и рекомендации экспресс-теста.
- `public/navigator/` — отдельное приложение анализа, вход `start.html`.
- `src/assets/` — локальные оригиналы фото и видео из проекта. В сборку попадают только используемые файлы.
- `src/styles.css` — цвета, типографика, стили и анимации.

Отзывы и кейсы сохранены как учебные примеры. Перед коммерческим использованием замените их подтверждёнными материалами. Список компаний и опыт перенесены из предоставленного архива; их подтверждение остаётся за владельцем сайта.

## Заявки

По умолчанию учебная форма скачивает TXT на устройство посетителя. Она явно сообщает, что отправка консультанту не подключена. Все поля теста, расчёта и вручную введённый текст сохраняются в сообщении. О подключении реальной отправки читайте `DEPLOYMENT.md`; настройки перечислены в `.env.example`.

## Серверный исходник

Архив был приложением TanStack Start/Nitro с Supabase и почтой Lovable. Его серверные модули и маршруты сохранены для дальнейшей работы, исходные зависимости находятся в `package.lovable.json`, исходная конфигурация Vite — в `vite.lovable.config.ts`. Они не входят в текущую статическую сборку. Для возврата к серверному приложению потребуется отдельная настройка, восстановление серверного вызова формы и тестирование; это не переключение одного флага. Исходные серверные/маршрутные тесты оставлены, но не запускаются командой статической версии `npm test`.

В текущей версии проверяются модель скидок и поведение используемого интерфейса. Отдельно проведено сравнение рекомендаций теста с прежним лендингом. Полные браузерные проверки в среде подготовки были недоступны.
