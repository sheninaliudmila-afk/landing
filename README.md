В корне лежит готовая сборка GitHub Pages с базовым путём `/landing/`. Для другого домена используйте готовый ZIP либо выполните `cd source`, `npm ci`, `npm run build` и загрузите содержимое `source/dist/` в корень хостинга.

После изменения исходников выполните `npm run typecheck`, `npm test`, `npm run build:pages`, затем обновите опубликованный корень из `source/dist-pages/` и сохраните обычный коммит. Историю не переписывайте.

Форма учебная: сохраняет TXT на устройстве, отправка консультанту не подключена. Навигатор открывается отдельно. Отзывы и кейсы — демонстрационные примеры.
