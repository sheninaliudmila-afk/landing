# FINCONSULT

Лендинг финансового консультанта и отдельный навигатор анализа компании. Статический сайт на HTML, CSS и JavaScript; сборка и Node.js на сервере не нужны.

## Публикация через GitHub Pages

1. Загрузить файлы в ветку `main`, сохранив `index.html` в корне репозитория.
2. Открыть **Settings → Pages**.
3. Выбрать **Deploy from a branch**, ветку **main**, папку **/ (root)** и сохранить.
4. Дождаться успешной публикации. Для репозитория `sheninaliudmila-afk/landing` стандартный адрес — `https://sheninaliudmila-afk.github.io/landing/`.

Файл `.nojekyll` отключает обработку Jekyll. Относительные пути рассчитаны на размещение сайта в подпапке репозитория GitHub Pages и на обычном домене.

Расширенный анализ открывается кнопкой в новой вкладке: `navigator/index.html#start`. Обратная ссылка ведёт на главную страницу этого же сайта.

## Собственный домен

Позже указать домен в **Settings → Pages → Custom domain** и настроить DNS у регистратора по актуальным указаниям GitHub Pages. Включить **Enforce HTTPS** после выдачи сертификата. Домен и записи DNS пока не заданы.

## Редактирование

- `index.html` — тексты, блоки, тарифы и основная кнопка анализа.
- `styles.css`, остальные CSS — оформление и адаптивность.
- `app.js` — меню, диалоги и учебная контактная форма.
- `carousel.js` — карусель.
- `quiz-model.js`, `quiz.js` — экспресс-тест.
- `discount-model.mjs`, `calculator.js` — правила и интерфейс калькулятора.
- `navigator/` — самостоятельный финансовый навигатор.
- `assets/`, `navigator/assets/` — локальные медиа и шрифты.

Калькулятор импортирует JavaScript-модуль `discount-model.mjs`. Проверять сайт нужно через HTTP(S), не двойным щелчком через `file://`. После размещения необходимо проверить правильный MIME JavaScript для `.mjs` и отсутствие ошибок загрузки в браузере.

## Текущее состояние

Это учебная версия. Отзывы, портреты клиентов, результаты кейсов, сроки и цены демонстрационные. Реальная отправка заявок, бронирование, оплата, CRM и платный доступ не подключены. Основная форма показывает учебное подтверждение; навигатор позволяет скачать локальный черновик.

Фото консультанта подготовлено по визуальному образцу. Утверждения об опыте и компаниях перенесены из предоставленного исходного HTML; перед рабочим коммерческим запуском владелец должен подтвердить или заменить их.

Репозиторий не содержит служебных настроек Sites, токенов, закрытых архивов передачи или внутреннего ТЗ. Шрифты передаются с лицензией в `assets/manrope-license.txt` и `navigator/assets/manrope-license.txt`.
